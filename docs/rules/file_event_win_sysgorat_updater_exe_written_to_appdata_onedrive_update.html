Updater.EXE Written To AppData Onedrive Update Folder

HighExperimentalWindows · file event
Download .yml View on GitHub

What it detects

Detects creation of Updater.exe inside a folder named "Onedrive Update" under the user's roaming AppData (%APPDATA%).

Why this rule exists

Unit 42 reports that the Windows build of SysGoRAT, the Go-based WebSocket RAT used by activity cluster CL-UNK-1211, persists as follows:

"The malware copies itself to %APPDATA%\Onedrive Update\Updater.exe and adds a Run key to HKCU".

The folder name is attacker-chosen; genuine Microsoft OneDrive installs under %LOCALAPPDATA%\Microsoft\OneDrive or Program Files and does not use a "Onedrive Update" folder in roaming AppData.

The Run key pointing into AppData\Roaming is already caught generically by SigmaHQ registry_set_susp_run_key_img_folder.yml; this rule covers the file drop itself.
