SUID Bit Set On Hidden File Or .tourch SUID Bash Copy Executed - Linux

HighExperimentalLinux · process creation
Download .yml View on GitHub

What it detects

Detects either of two steps of a hidden SUID shell backdoor:

Why this rule exists

(1) chmod setting the SUID bit (u+s) on a hidden dot-file, and (2) execution of a binary named .tourch.

Unit 42 reports that CL-UNK-1211 copied /bin/bash to a hidden file named .tourch and set the SUID bit on it ("modified its permissions using the command chmod u+s"), noting:

"Because .tourch is actually the /bin/bash binary, this allowed the attackers to execute bash commands as root." The .tourch name is attacker-chosen (a hidden misspelling of "touch"); the chmod branch covers the same technique under any hidden file name.
