Image Signed With Certificate Abused By SIDEEYE Loader

HighExperimentalWindows · image load
Download .yml View on GitHub

What it detects

Detects loading of an image signed with the Extended Validation certificate issued to "Tobias Weihmann Software Development OU" (via Sectigo).

Why this rule exists

UNC6240 (ShinyHunters) deployed Ple64.exe, a trojanized installer masquerading as Light Alloy that delivers the SIDEEYE backdoor, signed with this certificate.

Artifact-level indicator: it stops being useful once the certificate is revoked (GTIG requested revocation) or the actor re-signs.

Uses the Sysmon Event ID 7 Signature field; process_creation logs do not carry signer data.
