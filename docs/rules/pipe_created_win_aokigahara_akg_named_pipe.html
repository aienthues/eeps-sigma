Aokigahara Infostealer Akg_ Named Pipe Created

HighExperimentalWindows · pipe created
Download .yml View on GitHub

What it detects

Detects creation of or connection to a named pipe called akg_ followed by two hexadecimal values separated by an underscore.

Why this rule exists

Check Point's YARA rule for the Aokigahara infostealer contains the format string $str5 = "\\\\.\\pipe\\akg_%lx_%lx", which builds a pipe name of the form \\.\pipe\akg_<hex>_<hex>.

Sysmon records the pipe name without the \\.\pipe prefix (\akg_<hex>_<hex>), and %lx produces lower-case hexadecimal, which the regex matches.

The report does not describe the purpose of the pipe; the technique mapping is an analyst inference.
