NeedyMantis Firefox 21 User-Agent

MediumExperimentalWeb server · proxy
Download .yml View on GitHub

What it detects

Detects HTTP(S) requests whose user-agent contains "Firefox/21.0". Microsoft reports that the implant of the NeedyMantis malware family (used by at least Storm-3069) has a hard-coded user-agent of firefox/21.0 for its C2 connection, which is later converted to WebSockets. Firefox 21 dates from 2013, so genuine browser traffic with this version is rare in modern environments.

Why this rule exists

Requires proxy or TLS-inspection logs that record the user-agent of HTTPS requests. Matching is case-insensitive, covering both "firefox/21.0" (report prose) and "Firefox/21.0" (report hunting query).
