Scheduled Task SCAutoRepairEvery2Min Or SCAutoFix Script Created

HighExperimentalWindows · security
Download .yml View on GitHub

What it detects

Detects creation (Security event 4698) of a scheduled task named SCAutoRepairEvery2Min, or of any scheduled task whose action references the script SCAutoFix.ps1.

Why this rule exists

Huntress observed a phishing campaign that abused public Microsoft Power BI dashboards to deliver rogue ScreenConnect clients; in one incident "a Scheduled Task (SCAutoRepairEvery2Min)

was created and configured to run the script (SCAutoFix.ps1)", the PowerShell script that was deployed from the temp directory and installed a second, redundant ScreenConnect instance.

Both values are attacker-chosen artifacts. Requires "Audit Other Object Access Events" to be enabled.
