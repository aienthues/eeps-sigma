Zimbra JSP Written To Jetty Or Mailboxd Webapps By Shell Or Transfer Tool - Linux

HighExperimentalLinux · file event
Download .yml View on GitHub

What it detects

Detects a JSP file (.jsp or compiled _jsp.java) created under Zimbra's Jetty or mailboxd web application folders (/jetty_base/webapps/, /jetty/webapps/, /mailboxd/webapps/) by a shell or file transfer utility (sh, bash, dash, curl, wget, tee, base64, rsync).

Why this rule exists

After exploiting CVE-2026-73570, "Multiple JSP webshells were deployed across Jetty and mailboxd application paths", and rsync was used "to move staged payload fragments, helper scripts, and JSP webshells between nodes". The selection mirrors Microsoft's published hunting query.
