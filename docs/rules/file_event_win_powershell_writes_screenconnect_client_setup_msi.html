ScreenConnect Client MSI Installer Written By PowerShell

LowExperimentalWindows · file event
Download .yml View on GitHub

What it detects

Detects PowerShell writing a ScreenConnect client MSI installer (ScreenConnect.ClientSetup.msi) to disk.

Why this rule exists

Huntress observed a phishing campaign that abused public Microsoft Power BI dashboards to deliver rogue ScreenConnect clients; a PowerShell script (SCAutoFix.ps1) launched by the first rogue client "downloaded and executed the additional RMM installer (C:\Temp\ScreenConnect.ClientSetup.msi," to install a second ScreenConnect instance for redundant access.

Interactive installs normally arrive through a browser into the Downloads folder; a script-driven download of the client MSI is less common outside managed deployments.

The writer process (powershell.exe/pwsh.exe) is inferred from "a PowerShell script (SCAutoFix.ps1)" and "This script then downloaded..."; the report does not give the download method, so downloads made through curl.exe, certutil or BITS would be missed by this rule.

Most useful where ScreenConnect is not a sanctioned tool; where it is, tune by the deployment account (User), the known staging directory in TargetFilename, or the managed host group.
