Krita.DLL Loaded From Outside Program Files

MediumExperimentalWindows · image load
Download .yml View on GitHub

What it detects

Detects a process loading a DLL named Krita.dll from a location outside C:\Program Files\ or C:\Program Files (x86)\, a DLL sideloading pattern.

Why this rule exists

Sophos X-Ops lists the pair Krita.exe / Krita.dll among the signed-host / malicious-DLL pairs BRONZE SANDCASTLE used to sideload a loader that decrypts and runs a Meterpreter-based payload from config.ini. The selection keys on the DLL so that a renamed copy of the Krita host is still caught.

The report gives no folder paths; the filter is an ASSUMPTION based on Krita's well-known install locations (installer default C:\Program Files\Krita (x64)\, Microsoft Store builds under C:\Program Files\WindowsApps\, Steam builds under C:\Program Files (x86)\Steam\steamapps\common\) and is kept deliberately generic.
