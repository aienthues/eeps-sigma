ASPX Request To Documents MemberFiles Upload Directory

HighExperimentalWeb server · webserver
Download .yml View on GitHub

What it detects

Detects web requests for .aspx files under /documents/MemberFiles/, the member file upload folder of a multi-tenant recreation management platform.

Why this rule exists

Huntress observed an attacker register a member account, "upload malicious files directly to the /documents/MemberFiles/ directory" and use only the uploaded .aspx files (e.g. /documents/MemberFiles/12345_67890_<GUID>.aspx) to run commands as webshells. A user upload folder should not serve executable ASPX pages.
