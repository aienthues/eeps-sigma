Entra ID Device Named DESKTOP- Plus Eight Hex Characters

MediumExperimentalAzure · auditlogs
Download .yml View on GitHub

What it detects

Detects Entra ID audit events whose target device is named "DESKTOP-" followed by exactly eight uppercase hexadecimal characters (e.g. DESKTOP-54521F46).

Why this rule exists

Huntress reports that a token replay operator registered at least 48 rogue Entra-joined devices for persistence after signing in to the Device Registration Service, each "an Entra-joined device named `DESKTOP-` plus eight hex characters". The Windows default hostname is "DESKTOP-" plus seven characters, so the eight-character hex suffix sets these devices apart.

The report does not name the audit operation, and no SigmaHQ rule uses an Entra device-registration operation name, so the rule matches any audit event whose target resource carries such a name (device add, update, owner or user assignment). Treat the first event per device as the registration.
