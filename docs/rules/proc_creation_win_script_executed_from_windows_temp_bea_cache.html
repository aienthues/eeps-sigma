Script Executed From Windows Temp .bea-cache Folder

HighExperimentalWindows · process creation
Download .yml View on GitHub

What it detects

Detects a process command line referencing the C:\Windows\Temp\.bea-cache\ folder or the cs_disable.cmd script.

Why this rule exists

Sekoia reports that during the ShinyHunters Oracle PeopleSoft campaign "Attacks against security tools also included a small windows script that disables CrowdStrike EDR", hunted for as file path C:\Windows\Temp\.bea-cache\cs_disable.cmd or a command line containing cs_disable.cmd.

The folder and script names are attacker-chosen artifacts and are trivially changed.
