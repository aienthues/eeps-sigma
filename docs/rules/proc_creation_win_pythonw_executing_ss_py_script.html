Pythonw Executing Script Named ss.py

MediumExperimentalWindows · process creation
Download .yml View on GitHub

What it detects

Detects the windowless Python interpreter pythonw.exe running a script named ss.py.

Why this rule exists

Arctic Wolf Labs describes Microsoft Teams external-chat social engineering (fake IT support) leading to an MSI stager whose PowerShell script (cleaner.ps1)

extracts "the pythonw interpreter and implant (ss.py), both from the bundled archive6.zip". "After sleeping for five seconds, the implant is executed via pythonw.exe." Arctic Wolf assesses ss.py as a possibly new Python-based implant that queries Active Directory over LDAP and sends results to C2.

The report does not give the extraction folder or the exact command line, so the rule keys on the interpreter name and the script file name only.

The script-name strings require a path separator, a space or a quote before ss.py so that names such as class.py or process.py do not match.
