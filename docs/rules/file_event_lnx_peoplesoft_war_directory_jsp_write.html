JSP File Written To Oracle PeopleSoft Web Application Archive Directory - Linux

HighExperimentalLinux · file event
Download .yml View on GitHub

What it detects

Detects creation of JSP or JSPX files inside the PeopleSoft PSEMHUB.war or PORTAL.war web application directories on Linux (<PS_CFG_HOME>/webserv/<domain>/applications/peoplesoft/PSEMHUB.war/).

Why this rule exists

UNC6240 (ShinyHunters) exploited PSEMHUB (CVE-2026-35273) and wrote web shells (x.jsp, u.jsp, u2.jsp, sequentially numbered JSPs, Neo-reGeorg tunnel.jsp/tunnel.jspx) into PSEMHUB.war.
