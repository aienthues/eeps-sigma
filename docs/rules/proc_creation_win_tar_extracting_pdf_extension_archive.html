Tar Extraction Of File With PDF Extension

MediumExperimentalWindows · process creation
Download .yml View on GitHub

What it detects

Detects the built-in Windows tar.exe (bsdtar) extracting an archive whose command line references a .pdf file, i.e. a ZIP or other archive disguised with a PDF extension.

Why this rule exists

Huntress reports an Amazon-themed ClickFix campaign where the script "places the IronPython ZIP file in the user's Temp directory, as a file with a .pdf extension" and "then uses the tar command (which is now a part of modern Windows installations) to unpack the .zip". A PDF document cannot be extracted by tar, so a tar extraction naming a .pdf is file-type masquerading.

The report does not publish the tar arguments; matching the .pdf name on the tar command line assumes the archive is unpacked under its disguised name.

detection:
    selection_img:
        - Image|endswith: '\tar.exe'
        - OriginalFileName: 'bsdtar'
    selection_extract:
        CommandLine|contains:
            - '-x'
            - ' x'
            - '--extract'
    selection_pdf:
        CommandLine|contains: '.pdf'
    condition: all of selection_*
falsepositives:
    - Extracting a single named member that is a real PDF from a tar or zip archive (e.g. tar -xf docs.zip manual.pdf); check whether the archive argument itself ends in .pdf

Sysmon + Splunk Windows field mapping
source="WinEventLog:Microsoft-Windows-Sysmon/Operational" EventCode=1 Image="*\\tar.exe" OR OriginalFileName="bsdtar" CommandLine IN ("*-x*", "* x*", "*--extract*") CommandLine="*.pdf*"
Microsoft Defender XDR advanced hunting
DeviceProcessEvents
| where (FolderPath endswith "\\tar.exe" or ProcessVersionInfoOriginalFileName =~ "bsdtar") and (ProcessCommandLine contains "-x" or ProcessCommandLine contains " x" or ProcessCommandLine contains "--extract") and ProcessCommandLine contains ".pdf"

False positives & tuning
