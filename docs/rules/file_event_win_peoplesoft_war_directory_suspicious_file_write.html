Suspicious File Written To Oracle PeopleSoft Web Application Archive Directory - Windows

HighExperimentalWindows · file event
Download .yml View on GitHub

What it detects

Detects creation of JSP, JSPX or EXE files inside the PeopleSoft PSEMHUB.war or PORTAL.war web application directories.

Why this rule exists

UNC6240 (ShinyHunters) exploited PSEMHUB (CVE-2026-35273), wrote web shells (x.jsp, u.jsp and sequentially numbered JSPs) and other unexpected files such as tunnel.jsp and tunnel.jspx into PSEMHUB.war, then uploaded Ple64.exe, a trojanized installer delivering the SIDEEYE backdoor, in chunks through u.jsp and reassembled it in the same directory.

The report does not name the process that writes these files, so the rule does not filter on Image.
