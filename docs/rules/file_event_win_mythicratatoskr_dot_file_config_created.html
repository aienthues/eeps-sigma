Dot-Prefixed Updatecache Or Crond Config File Created In Windows Temp Or System32

HighExperimentalWindows · file event
Download .yml View on GitHub

What it detects

Detects creation of the dot-prefixed files .updatecache in C:\Windows\Temp or System32, or .crond in a Temp folder.

Why this rule exists

ESET reports that MythicRatatoskr keeps its AES-256-CFB encrypted configuration in "C:\Windows\Temp\.updatecache (in krbtman.exe, Act64.exe, ie.exe, ieupdate.exe, and windowsdefendersvc.exe)", in C:\Windows\system32\.updatecache, and in %LocalAppData%/Temp/.crond. Unix-style dot-file names are not used by Windows components.

ESET prints the .crond path with a forward slash, so both separators are matched.
