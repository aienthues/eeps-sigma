Base64 Encoded Script Staged In Windows Temp

MediumExperimentalWindows · file event
Download .yml View on GitHub

What it detects

Detects creation of a .ps1.b64 or .js.b64 file (a Base64-encoded PowerShell or JavaScript file) in C:\Windows\Temp\.

Why this rule exists

Through ASPX webshells, the attacker staged Base64-encoded planter scripts in C:\Windows\Temp (plant_ccrtc_mousewheel.ps1.b64, plant_ccrtc_fast.ps1.ps1.b64, ccrtc_sdk_init.js.b64)

and decoded them next to the originals (.ps1 / .js) before using them to trojanize a jQuery file on the site's login page.
