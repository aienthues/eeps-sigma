Zimbra Zmmailboxd.out Log Linked To PAM Sudo Config - Linux

HighExperimentalLinux · process creation
Download .yml View on GitHub

What it detects

Detects a process whose command line references both Zimbra's zmmailboxd.out log and pam.d/sudo (/etc/pam.d/sudo, absolute or relative), as when the log is replaced with a symbolic link to the PAM sudo configuration.

Why this rule exists

In post-exploitation of CVE-2026-73570 the attackers "backed up /etc/pam.d/sudo, replaced the legitimate zmmailboxd.out log with a symlink to the PAM configuration, and invoked the privileged zmmailboxdmgr process", so that the root-owned process overwrote the PAM file and a pam_exec hook could grant the zimbra account root.

The command line pattern is inferred from the described symlink step (e.g. ln -s); the report does not publish the literal command.
