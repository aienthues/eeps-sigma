Microsoft Edge Launched Off-Screen With 1x1 Window Or Base64 HTML Data URI

HighExperimentalWindows · process creation
Download .yml View on GitHub

What it detects

Detects msedge.exe started with the window position 10000,10000 together with a 1x1 window size or an inline base64 data:text/html URI.

Why this rule exists

Symantec reports that hosts infected with Swallowtail's Hookedge backdoor "fetch tasks using a hidden, off-screen instance of the Microsoft Edge browser", launched by a batch script as "start "" msedge.exe --window-size=1,1 --window-position=10000,10000 --ignore-certificate-errors" and "passing it an inline, base64-encoded JavaScript payload rather than a URL" ("data:text/html;base64,").

A window placed far off-screen at 1x1 pixels hides the browser from the user while it acts as the backdoor's HTTP client. The rule requires the off-screen position plus one of the other two arguments, so a different window size or a URL argument still matches through the other branch.

    condition: all of selection_*
