Portable Node.exe Executed From ProgramData Running JavaScript File

MediumExperimentalWindows · process creation
Download .yml View on GitHub

What it detects

Detects node.exe running from a folder under C:\ProgramData\ with a .js script on the command line.

Why this rule exists

Huntress reports an Amazon-themed ClickFix campaign in which the malware unpacks a portable Node.js runtime "to the location C:\ProgramData\NodeView, then runs the (non-malicious) node.exe interpreter, passing it the index.js file as an argument"; the heavily obfuscated index.js then fetches the next stage that leads to Lumma Stealer. Installed Node.js lives under Program Files or a user profile; a portable runtime dropped into ProgramData is typical of malware staging.

detection:
    selection_img:
        Image|startswith: 'C:\ProgramData\'
        Image|endswith: '\node.exe'
    selection_cli:
        CommandLine|contains: '.js'
    filter_optional_chocolatey:
        Image|startswith: 'C:\ProgramData\chocolatey\'
    filter_optional_scoop:
        Image|startswith: 'C:\ProgramData\scoop\'
    filter_optional_nvm:
        Image|startswith: 'C:\ProgramData\nvm\'
    condition: all of selection_* and not 1 of filter_optional_*
falsepositives:
    - Chocolatey nodejs.portable packages (filtered under C:\ProgramData\chocolatey\)
    - Global Scoop installs of Node.js (filtered under C:\ProgramData\scoop\)
    - nvm-windows installed to C:\ProgramData\nvm\ (filtered)
    - Vendor agents or management tools that bundle a Node.js runtime under ProgramData; verify the signer and allowlist the vendor folder
level: medium

| where ((FolderPath startswith "C:\\ProgramData\\" and FolderPath endswith "\\node.exe") and ProcessCommandLine contains ".js") and (not((FolderPath startswith "C:\\ProgramData\\chocolatey\\" or FolderPath startswith "C:\\ProgramData\\scoop\\" or FolderPath startswith "C:\\ProgramData\\nvm\\")))

False positives & tuning

  • Chocolatey nodejs.portable packages (filtered under C:\ProgramData\chocolatey\)
  • Global Scoop installs of Node.js (filtered under C:\ProgramData\scoop\)
  • nvm-windows installed to C:\ProgramData\nvm\ (filtered)
  • Vendor agents or management tools that bundle a Node.js runtime under ProgramData; verify the signer and allowlist the vendor folder
