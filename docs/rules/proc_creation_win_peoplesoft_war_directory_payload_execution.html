Payload Execution From Oracle PeopleSoft Web Application Archive Directory

HighExperimentalWindows · process creation
Download .yml View on GitHub

What it detects

Detects execution of, or command lines referencing, an executable inside the PeopleSoft PSEMHUB.war or PORTAL.war web application directory, and command lines referencing the SIDEEYE loader name Ple64.

Why this rule exists

Through a web shell, UNC6240 (ShinyHunters) checked the reassembled file size (for %F in (applications\peoplesoft\PSEMHUB.war\Ple64.exe) do @echo %~zF), launched it in the background (cmd.exe /c start /b "" applications\peoplesoft\PSEMHUB.war\Ple64.exe) and polled for it (tasklist | findstr /i Ple64).

The directory-based selections are TTP-level; the Ple64 selection is an artifact and is trivially renamed.

    selection_img_ext:

    selection_cli:
        CommandLine|re: '(?i)\\(PSEMHUB|PORTAL)\.war\\[^"\s]+\.exe'
    selection_artifact:
        - CommandLine|contains:
              - '\Ple64.exe'
              - ' Ple64.exe'

        - Image|endswith: '\Ple64.exe'
    condition: all of selection_img_* or selection_cli or selection_artifact

Sysmon + Splunk Windows field mapping
source="WinEventLog:Microsoft-Windows-Sysmon/Operational" EventCode=1
| rex field=CommandLine "(?<CommandLineMatch>(?i)\\\\(PSEMHUB|PORTAL)\\.war\\\\[^\"\\s]+\\.exe)"
| eval CommandLineCondition=if(isnotnull(CommandLineMatch), "true", "false")
| search (Image IN ("*\\PSEMHUB.war\\*", "*\\PORTAL.war\\*") Image="*.exe") OR CommandLineCondition="true" OR CommandLine IN ("*\\Ple64.exe*", "* Ple64.exe*", "*findstr /i Ple64*") OR Image="*\\Ple64.exe"
