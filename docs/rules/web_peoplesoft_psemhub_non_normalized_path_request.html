Oracle PeopleSoft PSEMHUB Request Via Non-Normalized Path

HighExperimentalWeb server · webserver
Download .yml View on GitHub

What it detects

Detects requests to the Oracle PeopleSoft PSEMHUB servlet through a percent-encoded or non-canonical-case path such as /%50SEMHUB/.

Why this rule exists

UNC6240 (ShinyHunters) bypassed string-based WAF rules by URL-encoding one character (/%50SEMHUB/ in place of /PSEMHUB/)

and sent bursts of POST requests carrying serialized Java objects to /%50SEMHUB/hub (CVE-2026-35273 Java deserialization).

The report says to assume any percent-encoded, mixed-case or otherwise non-normalized variant of /PSEMHUB/.

Requires access logs that record the raw, undecoded URI (WebLogic PIA access log, reverse proxy or WAF). Logs that store the decoded path will not show the encoding.
