Scheduled Task Named Onedrive Created

MediumExperimentalWindows · security
Download .yml View on GitHub

What it detects

Detects creation (Security event 4698) of a scheduled task whose name is Onedrive, in any task folder.

Why this rule exists

Unit 42 reports that the Windows build of SysGoRAT (CL-UNK-1211) "Creates a daily scheduled task named Onedrive" as a persistence method.

Legitimate Microsoft OneDrive tasks carry longer names such as "OneDrive Standalone Update Task-S-1-5-21-..." or "OneDrive Reporting Task-S-1-5-21-...", so a match on the bare task name Onedrive is specific. Requires "Audit Other Object Access Events" to be enabled.
