Executable Launched Directly From ProgramData Intel Folder

MediumExperimentalWindows · process creation
Download .yml View on GitHub

What it detects

Detects a process whose image sits directly in C:\ProgramData\Intel\, not in a subfolder.

Why this rule exists

Kaspersky reports that the BlackX UEFI bootkit installer, which Kaspersky attributes to APT41 with medium confidence, was staged in that vendor-looking folder:

"The installer was launched with the command line C:\ProgramData\Intel\inst.exe PVMDIJGKAX2 Q46F6MDLI3RX2KV1".

The arguments are an RC4-encrypted payload file and its key, and inst.exe "does not contain any malicious strings". Name, arguments and hash are all trivially changed, so the rule keys on the location. Intel software that writes to ProgramData normally uses product subfolders (for example Package Cache), which the regex excludes by allowing no further path separator.
