Defender HideExclusionsFromLocalAdmins Value Set

MediumExperimentalWindows · registry set
Download .yml View on GitHub

What it detects

Detects the Microsoft Defender HideExclusionsFromLocalAdmins policy value being set to 1 (enabled) (HKLM\SOFTWARE\Policies\Microsoft\Windows Defender\HideExclusionsFromLocalAdmins).

Why this rule exists

Huntress notes that "attackers can set the following registry key value to "hide" exclusions from administrators when they try to query them", which hides attacker-added exclusions from local administrators. The value sits outside the \Windows Defender\Exclusions key, so existing Defender exclusion registry rules do not match it.
