Defender Exclusion Added Via MSFT_MpPreference CIM Method - PowerShell

MediumExperimentalWindows · ps script
Download .yml View on GitHub

What it detects

Detects a PowerShell script block that calls Invoke-CimMethod on the MSFT_MpPreference WMI class (root/Microsoft/Windows/Defender) with an ExclusionPath argument.

Why this rule exists

This adds a Microsoft Defender exclusion without the Add-MpPreference/Set-MpPreference cmdlets that existing exclusion rules look for.

Huntress attributes this method to GootKit, which "Creates an MDAV path exclusion via the MSFT_MpPreference WMI Class", e.g.

Invoke-CimMethod -Namespace root/Microsoft/Windows/Defender -ClassName MSFT_MpPreference -MethodName Add -Arguments @{ExclusionPath=@("C:\Temp"); ...}.

Requires PowerShell Script Block Logging (Event ID 4104).
