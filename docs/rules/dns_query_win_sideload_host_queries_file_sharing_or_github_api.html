DNS Query To File Sharing Or GitHub API By BRONZE SANDCASTLE Sideload Host

MediumExperimentalWindows · dns query
Download .yml View on GitHub

What it detects

Detects a DNS query for file.io, gofile.io, ably.net, ably.io or api.github.com made by one of the legitimate executables that Sophos X-Ops reports BRONZE SANDCASTLE abused as DLL sideloading hosts (SandboxieWUAU.exe, Krita.exe, NvdaHelper.exe, Vmmap.exe, LineAppMgr.exe, bginfo64.exe). The sideloaded Meterpreter-based payload runs inside the host process; Sophos reports it "reaching out to legitimate websites such as file[.]io, gofile[.]io, ably[.]net, and ably[.]io" (possibly for C2 tasking) and "communicating with github[.]com repositories to download encrypted config files" via api.github.com. None of these hosts has a legitimate reason to contact these services.

Why this rule exists

The javaw.exe, Jcef_helper.exe and generically named Start.exe hosts from the same report are intentionally omitted because Java applications and JCEF-based IDEs legitimately call api.github.com.
