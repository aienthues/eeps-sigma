Solarwinds.StatusLog.txt Credential Log Created - Linux

MediumExperimentalLinux · file event
Download .yml View on GitHub

What it detects

Detects creation of a file named Solarwinds.StatusLog.txt on a Linux host.

Why this rule exists

Unit 42 reports that CL-UNK-1211 inserted a credential logger into a PHP login page and that "The attackers named the log file Solarwinds.StatusLog.txt, to mimic legitimate SolarWinds activity in the environment." The name is attacker-chosen; the writing process is typically the PHP worker or web server user. The report does not give the directory, so the rule matches the file name anywhere.
