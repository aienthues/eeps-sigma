Service Installed With ImeBroker.exe From System32 RasConv Folder

HighExperimentalWindows · system
Download .yml View on GitHub

What it detects

Detects installation of a Windows service (System event 7045) whose image path is ImeBroker.exe in the non-standard folder C:\Windows\System32\RasConv\.

Why this rule exists

Kaspersky reports that the Lazarus TouchHub installer "copies the legitimate printfilterpipelinesvc.exe to C:\Windows\System32\RasConv\ImeBroker.exe", places the TouchShift loader beside it as mscoree.dll for side-loading, and registers a service that "runs the hard-coded command line C:\Windows\System32\RasConv\ImeBroker.exe -TimeBroker". The service name is dynamic (a netsvcs service name plus two random letters), so the rule keys on the image path.
