PHP Auto_prepend_file Directive Modified In System Or Plesk PHP Configuration - Linux

MediumExperimentalLinux · process creation
Download .yml View on GitHub

What it detects

Detects a command line that references both the PHP auto_prepend_file directive and the system (/etc/php/) or Plesk (/opt/plesk/php/) PHP configuration trees, excluding read-only viewers.

Why this rule exists

Unit 42 reports that, to make their web shell load before every PHP script, "the attackers modified the auto_prepend_file value across all PHP configurations under the directories /etc/php/ and /opt/plesk/php/".

The report does not show the exact modification command; this rule targets the common pattern of editing php.ini files in bulk with sed, perl, echo or tee.

Edits made directly by a PHP web shell (file writes without a child process) are not visible to this rule.
