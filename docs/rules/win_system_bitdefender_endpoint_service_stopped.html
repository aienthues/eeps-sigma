Bitdefender Endpoint Service Stopped

MediumExperimentalWindows · system
Download .yml View on GitHub

What it detects

Detects the Service Control Manager reporting (System event 7036) that a Bitdefender Endpoint service entered the stopped state.

Why this rule exists

Huntress reports that during an Akira ransomware intrusion "the threat actor accessed the BitDefender console, and several Windows services associated with the antivirus application were stopped", visible as "Service Control Manager/7036;Bitdefender Endpoint Update Service,stopped". Because the stop was driven from the management console rather than a local command line, process-creation rules for sc.exe/net.exe service tampering do not see it; the System log state change does. param1 and param2 are localized, so 'stopped' only matches English-language systems.
