Hidden Executable In x86_64-linux-gnu Library Directory Or .libpython-helper Executed - Linux

MediumExperimentalLinux · process creation
Download .yml View on GitHub

What it detects

Detects execution of a hidden (dot-prefixed) executable from /usr/lib/x86_64-linux-gnu/, or of any binary named .libpython-helper.

Why this rule exists

Unit 42 reports that CL-UNK-1211 copied a Python interpreter and "renamed it to .libpython-helper to execute shell commands with high privileges".

The extracted observables place it at /usr/lib/x86_64-linux-gnu/.libpython-helper. The name is attacker-chosen; the behavioural branch covers the same placement (a hidden executable among shared libraries) under any name.
