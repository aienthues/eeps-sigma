Executable Written To SYSVOL Scripts Folder By DFS Replication Service

MediumExperimentalWindows · file event
Download .yml View on GitHub

What it detects

Detects the DFS Replication service (dfsrs.exe) writing an executable under the SYSVOL\domain\scripts folder on a domain controller.

Why this rule exists

Symantec reports that the Warlock ransomware attackers staged run.exe and rune.exe in SYSVOL\domain\scripts\run, and that telemetry recorded dfsrs.exe, "the process responsible for replicating SYSVOL between domain controllers", as the parent that delivered run.exe and rune.exe, confirming the payload spread via ordinary SYSVOL replication.

DFSR may first write replicated files into its DfsrPrivate staging folders, so coverage depends on how the EDR attributes the final file write.
