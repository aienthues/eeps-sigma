Findstr Search For Payment Card Data Fields

MediumExperimentalWindows · process creation
Download .yml View on GitHub

What it detects

Detects findstr.exe run with payment card field names (CVV, CardNumber, CreditCard, CCNumber, card_number, first_six, last_four) as search strings.

Why this rule exists

Through ASPX webshells on IIS servers of a recreation management platform, the attacker searched web application source and payment webhook logs for cardholder data, e.g.

findstr /s /i /m /c:"CVV" /c:"CardNumber" /c:"CreditCard" /c:"CCNumber" ... E:\Content\info\*.aspx and findstr /i "exp_date exp_month exp_year expiration cvv first_six last_four card_number" E:\Content\info\_fortis\Webhooks\<date>.txt.
