MeshAgent Executed From Temporary Directory - Linux

HighExperimentalLinux · process creation
Download .yml View on GitHub

What it detects

Detects the MeshCentral agent (meshagent) running from a world-writable temporary directory on Linux.

Why this rule exists

UNC6240 (ShinyHunters) dropped unencrypted meshagent binaries and configuration (meshagent, meshagent.msh, meshagent.db) directly into /tmp under the PeopleSoft service account and used it as a remote access channel to Microsoft-masquerading domains.

Legitimate MeshCentral installs run from an installation directory such as /usr/local/mesh_services/, not /tmp.
