Aokigahara Infostealer Kmd_w_ Staging Database File Created

MediumExperimentalWindows · file event
Download .yml View on GitHub

What it detects

Detects creation of a file named kmd_w_<number>_<number>.db.

Why this rule exists

Check Point's YARA rule for the Aokigahara infostealer contains the format string $str10 = "%s\\kmd_w_%d_%d.db", a .db file written into a folder that the report does not name.

The rule matches the verbatim file-name pattern with %d as decimal digits and ignores the folder. The report does not describe the file's purpose; a staging copy of a locked SQLite store is an analyst inference.
