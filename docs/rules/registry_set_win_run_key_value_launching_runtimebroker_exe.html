Run Key Value Launching RuntimeBroker.EXE

HighExperimentalWindows · registry set
Download .yml View on GitHub

What it detects

Detects a CurrentVersion\Run value whose data points to RuntimeBroker.exe, or the Run value name "MicrosoftRuntime".

Why this rule exists

Unit 42 reports that ShelbyLoader V2 (Blinder Tunnel campaign) copies a renamed benign Microsoft binary, RuntimeBroker.exe, into the deceptive folder %LOCALAPPDATA%\Microsoft\RuntimeBrokers and persists via "HKCU\SOFTWARE\Microsoft\Windows\CurrentVersion\Run\MicrosoftRuntime" pointing to "%LOCALAPPDATA%\Microsoft\RuntimeBrokers\RuntimeBroker.exe". The genuine Windows Runtime Broker is started on demand by the system (DCOM) and is not registered as a Run-key autostart, so any Run value launching a binary named RuntimeBroker.exe is anomalous.

Sysmon logs HKCU as HKU\<SID>, hence the contains/endswith matching on the key path below the hive.

The report states the value is re-written on a 120-second interval, so expect repeated events per host; deduplicate on host and TargetObject.
