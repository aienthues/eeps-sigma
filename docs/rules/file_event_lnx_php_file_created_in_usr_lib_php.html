PHP File Created In /usr/lib/php By Non-Package-Manager Process - Linux

MediumExperimentalLinux · file event
Download .yml View on GitHub

What it detects

Detects creation of a .php file under /usr/lib/php/ by a process other than a package manager, and the specific CL-UNK-1211 web shell file name plesk_sys_driver.php anywhere.

Why this rule exists

Unit 42 reports that CL-UNK-1211 dropped a PHP web shell at "/usr/lib/php/plesk_sys_driver.php", a system path and Plesk-like name chosen to look like a legitimate driver file, and then loaded it into every PHP script through auto_prepend_file.

/usr/lib/php/ normally holds PHP extension modules and helper scripts installed by the package manager, not PHP source files written at runtime.

Note: on RHEL-family systems yum/dnf run as Python, so the package-manager filter by Image may not match there; tune the filter for those hosts.
