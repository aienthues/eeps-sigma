Service Installed With Name Ieupdate

HighExperimentalWindows · system
Download .yml View on GitHub

What it detects

Detects installation of a Windows service (System event 7045) named ieupdate.

Why this rule exists

ESET reports that "MythicRatatoskr is started as a Windows service with the name ieupdate." The Go backdoor uses Yggdrasil for C2 and was deployed in the UAC-0099 / Sandworm intrusion; its binaries used names such as ieupdate.exe, krbtman.exe and windowsdefendersvc.exe. Internet Explorer has no service of this name.
