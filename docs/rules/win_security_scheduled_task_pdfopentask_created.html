Scheduled Task PdfOpenTask Created Or Updated

HighExperimentalWindows · security
Download .yml View on GitHub

What it detects

Detects creation or update (Security events 4698/4702) of a scheduled task named pdfopentask.

Why this rule exists

ESET reports, for the intrusion it investigated at the target organization, that "a scheduled task named pdfopentask was executed on one machine in the target organization" and that "It executed a PowerShell payload from %temp%\temporarydoc.txt".

The task name is an attacker-chosen artifact; requires "Audit Other Object Access Events" to be enabled.
