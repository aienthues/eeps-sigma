ScreenConnect RunFile Execution From Documents Temp Folder

LowExperimentalWindows · process creation
Download .yml View on GitHub

What it detects

Detects a process launched by ScreenConnect.WindowsClient.exe through ScreenConnect's built-in RunFile function where the parent command line references a file under the user's Documents ...\Temp\ folder (e.g. C:\Users\<user>\Documents\ScreenConnect\Temp\ or C:\Users\<user>\OneDrive\Documents\ScreenConnect\Temp\).

Why this rule exists

Microsoft observed unattributed phishing campaigns in which the actor, after deploying ScreenConnect through an abused MSP360 RMM agent, transferred executables into these folders and ran them via RunFile. The selection mirrors the advanced hunting query published in the report (ScreenConnect.WindowsClient.exe, RunFile, \Documents\, \Temp\).

Note: Documents\...\Temp\ is ScreenConnect's default RunFile staging folder, so this rule matches every RunFile use, legitimate or not; it is set to low (in line with SigmaHQ's ScreenConnect temp-file rule).

Raise the level only where ScreenConnect is not a sanctioned tool or where the ScreenConnect relay/instance is not a known company instance.
