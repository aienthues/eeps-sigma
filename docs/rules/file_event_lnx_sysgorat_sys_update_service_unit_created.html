SysGoRAT Sys-Update Systemd Service Unit Created - Linux

HighExperimentalLinux · file event
Download .yml View on GitHub

What it detects

Detects creation of the systemd unit file /etc/systemd/system/sys-update.service.

Why this rule exists

Unit 42 documents the "persist" command of SysGoRAT, the Go-based WebSocket RAT used by activity cluster CL-UNK-1211, whose systemd method "writes a unit (service) file to /etc/systemd/system/sys-update.service; reloads and enables the service".

The unit name is hard-coded in the malware and is not shipped by any mainstream distribution package.
