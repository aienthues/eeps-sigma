Python Tunneling Implant Client.py Executed From Users Public Indigo Folder

HighExperimentalWindows · process creation
Download .yml View on GitHub

What it detects

Detects a process whose image is located in \Users\Public\indigo\ and whose command line references client.py.

Why this rule exists

Sophos X-Ops reports that in the STAC4924 campaign (TerminalFix lures leading to Lorem Ipsum Loader) the malware deployed a portable Python runtime to the Users\Public\indigo directory by downloading the legitimate Python embedded package from python.org, and the runtime was used to execute client.py, a custom tunneling implant that opens an encrypted WebSocket connection to attacker-controlled servers to relay traffic into the network. The report does not name the Python executable, so the rule keys on the folder and script name.

Sophos tracks the campaign as STAC4924 and assesses with moderate confidence that its two phases are linked to the same threat group or to closely associated threat actors.
