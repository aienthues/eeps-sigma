File Created In AppData Local PowershellCleaner Scripts Folder

HighExperimentalWindows · file event
Download .yml View on GitHub

What it detects

Detects creation of any file in the \AppData\Local\PowershellCleaner\scripts\ folder.

Why this rule exists

Arctic Wolf Labs describes Microsoft Teams external-chat social engineering (fake IT support) in which the victim ran PowerShell that downloaded an MSI from Azure Blob Storage bundling a PowerShell script and a ZIP archive (archive6.zip). The bundled script (cleaner.ps1) "is dropped into the users' AppData folder (AppData\Local\PowershellCleaner\scripts) and executed"; it extracts a pythonw interpreter and a Python implant (ss.py) from archive6.zip.

In the rule author's assessment (not a claim made by the report), PowershellCleaner is not a known Microsoft or common third-party folder. The rule matches the folder rather than only cleaner.ps1 so a renamed script is still caught.

The report does not say where archive6.zip, pythonw.exe or ss.py are written, so those files are not part of this rule.
