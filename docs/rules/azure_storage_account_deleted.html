Azure Storage Account Deleted

LowExperimentalAzure · activitylogs
Download .yml View on GitHub

What it detects

Detects deletion attempts of Azure Storage Accounts. This is a base rule for threshold alerting.

Why this rule exists

Storm-3168 used a compromised service principal to make 100+ storage account deletion attempts in a destructive sequence lasting about 7 minutes; most targeted storage accounts were deleted, and deletion attempts were also made against Azure Site Recovery and Azure Backup protection locks protecting storage accounts.

Recommended aggregation: alert when one Caller produces deletion attempts against 10+ distinct ResourceId values (count Success and Failure; exclude Start/Accept events to avoid double counting) within 10 minutes.

Raise severity when ResourceId contains backup, recovery or asr, or when the target is one of the Site Recovery related storage accounts.

The operationName is the standard ARM operation for storage account deletion.
