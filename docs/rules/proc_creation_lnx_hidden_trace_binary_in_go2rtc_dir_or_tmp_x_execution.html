Hidden .trace Binary In go2rtc Directory Or /tmp/.x Executed - Linux

HighExperimentalLinux · process creation
Download .yml View on GitHub

What it detects

Detects execution of a hidden binary named .trace from a go2rtc configuration directory or /dev/shm, or of a binary located at or under /tmp/.x.

Why this rule exists

Symantec reports that the Skynet LLMjacking agent's day-2 script would "deploy cryptocurrency miners quietly in the background, hidden under /tmp/.x", and searched "/config /opt/go2rtc /etc/go2rtc ~/.config/go2rtc /dev/shm" and "placed the miner in the first one it found as a hidden file named .trace".

The names are attacker-chosen, but a hidden executable in a smart-camera gateway's config directory is unusual on its own.
