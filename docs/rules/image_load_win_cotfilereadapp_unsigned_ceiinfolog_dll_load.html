Unsigned Ceiinfolog.DLL Loaded By Canon COTFileReadApp.EXE

HighExperimentalWindows · image load
Download .yml View on GitHub

What it detects

Detects the Canon-signed COTFileReadApp.exe loading an unsigned ceiinfolog.dll, a DLL sideloading pattern.

Why this rule exists

Huntress reports an unattributed ClickFix campaign (lures delivered through a malicious ChatGPT Custom GPT) in which an MSI installed COTFileReadApp.exe into %LOCALAPPDATA%\Programs\Advanced Printer Configuration Reader\ next to a malicious ceiinfolog.dll; the payload was a remote access trojan that the report does not name.

Huntress lists "An unsigned ceiinfolog.dll ... in the same folder as COTFileReadApp.exe" as an indicator. The rule keys on the signature status reported by Sysmon EID 7 and does not depend on the actor-chosen install folder. The later V2 variant moved to a different signed host (Stardock DeElevate64.exe) and is not covered.
