AI Assistant Or Developer CLI Auth Token Files Accessed By Uncommon Process

MediumExperimentalWindows · file access
Download .yml View on GitHub

What it detects

Detects a process other than the owning tool accessing authentication or token files of AI coding assistants and AI-enabled developer CLIs (Claude Code credentials, Codex auth.json, Kiro auth token and profile, GitHub Copilot hosts.json, Gemini CLI workspace token and master key, Amazon Q data store).

Why this rule exists

Check Point reports that the Aokigahara infostealer's "aisessions" handler "targets AI applications and development tools" and collects "authentication files, session data, and configuration files associated with AI-assisted development and cloud environments"; "The paths below identify the handler's collection targets." The report gives each path relative to an unnamed base folder (%s), so the rule matches the verbatim path suffixes only. For Claude Code it matches a credentials.json file under a .claude folder, which also covers the dot-prefixed .credentials.json name.

State databases shared by many editor processes (state.vscdb, storage.json) and AWS CLI credential files are left out because every IDE, SDK and extension reads them.

Owner filters are assumed default image names, not from the report: claude.exe, codex.exe, Kiro.exe, Code.exe, Cursor.exe, Windsurf.exe and Amazon Q q.exe/qchat.exe under a user profile or Program Files. An optional filter excludes node.exe, which runs npm-installed Gemini CLI, Copilot CLI and Codex; removing it restores visibility of Node.js-based stealers at the cost of more noise. A stealer that renames itself to an owner image name evades the rule.

False positives & tuning

  • The owning AI tool or CLI installed under a different image name or path (for example JetBrains IDE AI plugins reading Copilot hosts.json, or Python-based CLIs); add those images to the filter after review
  • Backup, file-sync and third-party antivirus scanners running from outside Program Files that read the user profile
  • Users opening these files in a text editor
