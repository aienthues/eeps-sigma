Sshpass Inline Password With Host Key Checking Disabled - Linux

MediumExperimentalLinux · process creation
Download .yml View on GitHub

What it detects

Detects sshpass supplying a password on the command line ("sshpass -p", including the -pPASSWORD form) to an SSH session that disables host key verification (StrictHostKeyChecking=no).

Why this rule exists

Unit 42 reports that CL-UNK-1211 moved laterally between Linux servers with "sshpass -p [PASSWORD] ssh -o StrictHostKeyChecking=no -o ConnectTimeout=5 [USERNAME]@[IP_ADDRESS] [COMMAND] 2>&1".

The combination lets a script push commands to many hosts with harvested credentials without interactive prompts.

The 'sshpass -p' match is a case-sensitive regex so the -P (prompt string) option is excluded.
