HTTP POST To Infostealer Gate Endpoint

LowExperimentalWeb server · proxy
Download .yml View on GitHub

What it detects

Detects HTTP POST requests whose URI path ends in /gate, optionally followed by a query string, a C2 panel endpoint used by commodity infostealers to receive stolen data.

Why this rule exists

Symantec reports that the Aoki infostealer "collects the available data from victim machines and sends it to its C&C server, using a /gate endpoint".

The path alone is a weak, easily changed indicator and /gate routes also exist in legitimate web applications, so this is a low-severity hunting rule; prioritise hits to rare or newly seen hosts, bare-IP destinations and non-browser user agents.

Symantec notes that "Older samples used an IP address and port 8080 over unencrypted HTTP"; the report also lists domain-based C2 servers, so the rule does not require an IP or port, and if C2 traffic is HTTPS the rule needs proxy or TLS-inspection logs that record the URI.
