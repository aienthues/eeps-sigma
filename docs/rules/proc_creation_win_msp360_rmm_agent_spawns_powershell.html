PowerShell Spawned By MSP360 RMM Agent

LowExperimentalWindows · process creation
Download .yml View on GitHub

What it detects

Detects PowerShell launched by the MSP360 RMM agent service (RMM.Agent.exe).

Why this rule exists

Microsoft observed unattributed phishing campaigns that distributed the legitimate MSP360 RMM installer under deceptive names; after installation "the newly installed RMM.Agent.exe service launched PowerShell", which changed the session execution policy and downloaded ClientSetup.msi (ScreenConnect) with Invoke-WebRequest, then installed it silently with msiexec /qn.

The report's hunting query notes the spawned PowerShell command line is just "powershell.exe" (commands supplied without arguments), so enable script block logging to see the payload.

Most useful in environments where MSP360 is not a sanctioned RMM tool.

False positives & tuning

  • Every PowerShell script or remote command pushed through a sanctioned MSP360 deployment (C:\Program Files\RMM Agent\ is the vendor's default install folder); exclude where MSP360 is approved
  • Other software installed into a folder named "RMM Agent" with an RMM.Agent.exe binary that launches PowerShell
